## Phase 0 gate

- [ ] Unity opens and compiles without errors
- [ ] URP, Input System and Cinemachine configured
- [ ] Git, Git LFS and assembly definitions in place
- [ ] Blender sample asset imports at correct scale
- [ ] Left/right movement, jump and double jump work
- [ ] Orthographic camera follows without jitter
- [ ] Tests pass and Windows build is produced where tooling allows
- [ ] Independent QA reports PASS or clearly documents blockers

## Release strategy

Release 1: polished early game and two bosses. Release 2: six bosses, three classes and advanced equipment. Release 3: late-game mastery and eventually cooperative play.
